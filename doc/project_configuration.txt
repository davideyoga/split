Prisma: 
    Nella root del progetto lanciare: npx prisma init --db
    Configurare link .env per collegare al DB
    Configurare DataModel dentro prisma/schema.prisma
    Lanciare comando per inizializzare DB: npx prisma migrate dev --name {nomeCommitDataModel}
    Per rigenerare i file di prisma: npx prisma generate
    Per resettare il db: npx prisma migrate reset
    Per aprire Prisma Studio: npx prisma studio
